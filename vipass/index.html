VIPASS情報処理技術者試験 模擬検定システム

VIPASS は、キーボードだけで四肢択一の問題に解答できる模擬検定システムです。 視覚障害者向け「日商PC検定3級」模擬検定システムのキー操作を参考に、 情報処理技術者試験の形式へ割り当て直しています。 操作はすべて Alt との同時押しです。 スクリーンリーダを使わない方にも、目と手を動かさずに解答できる方法として利用できます。

1. 読み上げの方法を選ぶ

読み上げ方法

スクリーンリーダ（NVDA、PC-Talker、JAWS、ナレーター、VoiceOver など）をお使いの方は 「スクリーンリーダで読む」のままにしてください。二重に読み上げられるのを防ぎます。

2. キー操作の設定

キー操作

固定キー方式は、Alt を押して離すと5秒間だけ「入力待ち」になり、 その間に押したキーが Alt との同時押しとして扱われます。 Windows のキーボード設定にある「固定キー機能」とは独立して動きます。

3. 試験の設定

試験

問題を移動したときの読み上げ

読み込まない場合は、内蔵のサンプル問題（10問）で受験します。

キー割当て一覧

すべて Alt と同時に押します。試験中は Alt+H でも読み上げます。

上段が問題文、中段が選択肢、下段が解答、左手側が移動という並びです。 次の図は、その並びをキーボードの位置のまま示したものです（同じ内容は下の表にもあります）。

Chrome と Edge がブラウザ自身で使うため、割当てを避けたキー: Alt+D（アドレスバー）、Alt+E と Alt+F（メニュー）、 Alt+Home、Alt+←、Alt+→。
