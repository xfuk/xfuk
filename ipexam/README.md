# 情報処理技術者試験 模擬検定システム（スクリーンリーダ対応）

キーボードだけで四肢択一問題に解答できる、ブラウザ完結の模擬検定Webアプリです。

視覚障害者向け「日商PC検定3級」模擬検定システム（日本視覚障害者職能開発センター）が
20年以上使ってきたキー操作を参考に、情報処理技術者試験の形式へ割り当て直しました。
問題文を「何文目」で呼び出せるので、長文問題を頭から読み直さずに済みます。
視覚障害のない受験者にとっても、マウスやタブ移動なしで解答できる操作系になっています。

## 使い方

`ipexam/index.html` をブラウザで開くだけです。ビルドもサーバも不要で、
ファイルを直接開いても（`file://`）動きます。

```
# ローカルサーバで開く場合（任意）
npx http-server ipexam -p 8080
```

`ipexam/dist/ipexam-standalone.html` は、CSS と JavaScript を1枚にまとめた配布用ファイルです。
このファイル1つをコピーするだけで動くので、USB メモリや LMS への設置に使えます。
更新するときは次のコマンドで作り直します。

```
node ipexam/tools/build-single.js
```

対応ブラウザは **Chrome / Edge**（Firefox は前提にしていません）。
起動画面で読み上げ方法・キー操作・制限時間を設定してから「試験を開始する」を押します。

## キー割当て

すべて <kbd>Alt</kbd> と同時押しです。固定キー方式を有効にすると、
<kbd>Alt</kbd> を押して離してから5秒以内に単独でキーを押す操作にもできます。

### 問題文（上段、左から右へ）

| キー | 動作 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>Y</kbd> | 全文を読む |
| <kbd>Alt</kbd>+<kbd>U</kbd> | 1センテンス目 |
| <kbd>Alt</kbd>+<kbd>I</kbd> | 2センテンス目 |
| <kbd>Alt</kbd>+<kbd>O</kbd> | 3センテンス目 |
| <kbd>Alt</kbd>+<kbd>P</kbd> | 4センテンス目 |
| <kbd>Alt</kbd>+<kbd>@</kbd> | 5センテンス目 |
| <kbd>Alt</kbd>+<kbd>[</kbd> | 次のセンテンスを読む（6文目以降はここで送る） |
| <kbd>Alt</kbd>+<kbd>]</kbd> | 図の説明を読む（図が複数あれば押すたびに次の図へ） |

### 選択肢を読む（中段）

| キー | 動作 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>J</kbd> | 選択肢アを読む |
| <kbd>Alt</kbd>+<kbd>K</kbd> | 選択肢イを読む |
| <kbd>Alt</kbd>+<kbd>L</kbd> | 選択肢ウを読む |
| <kbd>Alt</kbd>+<kbd>;</kbd> | 選択肢エを読む |

### 解答する（下段）

| キー | 動作 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>M</kbd> | 解答アを選択 |
| <kbd>Alt</kbd>+<kbd>,</kbd> | 解答イを選択 |
| <kbd>Alt</kbd>+<kbd>.</kbd> | 解答ウを選択 |
| <kbd>Alt</kbd>+<kbd>/</kbd> | 解答エを選択 |
| <kbd>Alt</kbd>+<kbd>C</kbd> | 選択を解除 |

### 移動（左手）

| キー | 動作 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>N</kbd> | 次の問題 |
| <kbd>Alt</kbd>+<kbd>B</kbd> | 前の問題 |
| <kbd>Alt</kbd>+<kbd>A</kbd> | 問題1番へ |
| <kbd>Alt</kbd>+<kbd>S</kbd> | 最終問題へ |
| <kbd>Alt</kbd>+<kbd>X</kbd> | 後ろの未回答問題へ |
| <kbd>Alt</kbd>+<kbd>Z</kbd> | 前の未回答問題へ |

### 情報を聞く

| キー | 動作 |
| --- | --- |
| <kbd>Alt</kbd>+<kbd>R</kbd> | 現在の状態を読む（例「問23、100問中。イを選択中」） |
| <kbd>Alt</kbd>+<kbd>T</kbd> | 残り時間 |
| <kbd>Alt</kbd>+<kbd>G</kbd> | 未回答問題の番号をすべて聞く |
| <kbd>Alt</kbd>+<kbd>H</kbd> | キー一覧を読む |
| <kbd>Alt</kbd>+<kbd>Q</kbd> | 終了 |

日商PC検定からの変更点は、未回答ジャンプを <kbd>F</kbd>・<kbd>D</kbd> から
<kbd>X</kbd>・<kbd>Z</kbd> へ移した点。新設は <kbd>[</kbd> <kbd>]</kbd> <kbd>R</kbd> <kbd>C</kbd> <kbd>H</kbd> の5つです。

### ブラウザに予約されていて使わないキー

Chrome / Edge が自分で使うため、次の組み合わせは割り当てていません。

<kbd>Alt</kbd>+<kbd>D</kbd>（アドレスバー）、<kbd>Alt</kbd>+<kbd>E</kbd> と <kbd>Alt</kbd>+<kbd>F</kbd>（メニュー）、
<kbd>Alt</kbd>+<kbd>Home</kbd>、<kbd>Alt</kbd>+<kbd>←</kbd>、<kbd>Alt</kbd>+<kbd>→</kbd>

### 操作の細かい挙動

- <kbd>Alt</kbd>+<kbd>U</kbd>〜<kbd>@</kbd> で読んだ位置は <kbd>Alt</kbd>+<kbd>[</kbd> に引き継がれます。
  3文目を読んでから <kbd>Alt</kbd>+<kbd>[</kbd> を押すと4文目が読まれます。
- <kbd>Alt</kbd>+<kbd>[</kbd> で末尾まで行くと「問題文は以上です」と案内し、次に押すと1文目に戻ります。
- <kbd>Alt</kbd>+<kbd>Q</kbd> は誤操作を防ぐため2回押しです。1回目で未解答数を知らせて確認し、
  もう一度押すと採点します。<kbd>Alt</kbd>+<kbd>C</kbd> で取り消せます。
- <kbd>Alt</kbd>+<kbd>X</kbd> / <kbd>Alt</kbd>+<kbd>Z</kbd> は末尾・先頭で折り返して探します。
- 解答は自動保存されるので、ブラウザを閉じても起動画面から続きを再開できます。

画面の配色は、標準ではお使いの環境の明るい／暗いの設定に追随します。
起動画面でハイコントラスト（黒地に黄色）と文字サイズ（1.0〜3.0倍）も選べます。
本文の書体には、読みやすさを目的に設計されたユニバーサルデザイン書体
BIZ UDPGothic を指定しています（入手できない環境ではメイリオなどに切り替わります）。

## 読み上げの仕組み

読み上げ方法は起動画面で3通りから選べます。

- **スクリーンリーダで読む**（既定）— `aria-live` のライブリージョンに文言を流します。
  NVDA、PC-Talker、JAWS、ナレーター、VoiceOver など、利用者がふだん使う音声で読まれます。
  同じ文言を連続して読ませるため、2つのライブリージョンを交互に使っています。
- **このブラウザの音声合成で読む** — Web Speech API を使います。スクリーンリーダを
  使っていない方向け。速さを 0.5〜3.0 倍で調整できます。
- **両方で読む**

「アプリケーションモード」を有効にすると、解答画面に `role="application"` を付け、
スクリーンリーダのブラウズモード（1文字ナビゲーション）より本システムのキー操作が
優先されます。<kbd>Alt</kbd> 併用なので通常は競合しませんが、確実にしたい場合に使ってください。

## キーボード配列

キーの判定は、まず `event.key`（入力された文字）、次に `event.code`（物理キー位置）で行います。
日本語配列（JIS）と英語配列（US）では <kbd>@</kbd> <kbd>[</kbd> <kbd>]</kbd> の位置が違うため、
起動画面で配列を明示することもできます。既定の「自動判定」では、記号キーの
`key` と `code` の組み合わせから配列を推定します。

macOS で <kbd>Option</kbd>+英字を押すと合成文字（例: <kbd>Option</kbd>+<kbd>J</kbd> → ∆）になりますが、
物理キー位置での判定にフォールバックするため、そのまま操作できます。

## 問題データを差し替える

起動画面の「問題ファイル（JSON）を読み込む」から、独自の問題セットを読み込めます。
書式は `data/sample-exam.json` を参照してください。

```json
{
  "title": "問題セットの名前",
  "timeLimitSec": 1800,
  "questions": [
    {
      "text": ["1文目。", "2文目。"],
      "figures": [{ "label": "図1　構成図", "description": "図の内容を文章で説明する。" }],
      "choices": ["アの本文", "イの本文", "ウの本文", "エの本文"],
      "answer": 1,
      "explanation": "採点後に表示・読み上げされる解説。"
    }
  ]
}
```

- `text` は**1文ずつ**配列に分けます。この配列の要素が
  <kbd>Alt</kbd>+<kbd>U</kbd>〜<kbd>@</kbd>、<kbd>Alt</kbd>+<kbd>[</kbd> の読み上げ単位になります。
  文字列で書いた場合は「。」で自動分割します。
- `figures` は図を**文章で**説明したものです。画像そのものは扱いません。
- `answer` は 0 が ア、1 が イ、2 が ウ、3 が エ。省略すると採点対象外になります。

同梱のサンプル10問は、情報処理技術者試験の出題形式にならって作成した自作問題です
（過去問題の転載ではありません）。

## ファイル構成

```
ipexam/
├── index.html                起動画面・解答画面・結果画面
├── assets/
│   ├── css/style.css         表示（ハイコントラスト、文字サイズ）
│   └── js/
│       ├── keymap.js         キー割当ての定義と、key / code による解決
│       ├── speech.js         ライブリージョンと音声合成の読み上げ
│       ├── data.js           内蔵のサンプル問題
│       └── app.js            試験の進行、解答、採点、キー入力の処理
└── data/sample-exam.json     問題ファイルの書式サンプル
```
