# サウンド校正アシスト(Word アドイン)

スペルミス・文法エラーの下線は見落とされやすく、視覚障害のある利用者には確認が難しい場合があります。
本アドインは Microsoft Word の文書を監視し、誤りが現れたときに効果音(イヤコン)と音声読み上げで通知します。
評価実験のために、通知から修正までの時間などを記録するログ機能も備えています。

## 前提となる制約

Word の JavaScript API (Office.js) は、Word 標準のスペルチェック・文章校正の結果(VBA/COM の `Range.SpellingErrors` に相当する情報)を公開していません。
そのため本アドインは、文書のテキストを取得して独自に検査し、その結果を通知します。
検査方法は次から選べます。

- 内蔵チェッカー: オフラインで動作。ユーザー辞書(誤り→正しい語)と正規表現ルール(単語の重複、冠詞 a/an、文頭の小文字、句読点の連続など)。
- LanguageTool: オープンソースの校正エンジンの HTTP API。英語のスペル・文法に強く、自前サーバーも指定可能。日本語の対応は限定的。
- 両方: 上の 2 つを併用。

評価実験では、文書に埋め込む誤りをユーザー辞書に登録しておけば、内蔵チェッカーが確実に検出します。

## 通知の手段

- 効果音: 種別ごとに異なる短い合成音(スペル: 下降 2 音、文法: 低い長音、表記: 短いクリック、修正: 上昇 2 音)。プリセットで差し替え可能。
- 読み上げ: Web Speech API で「スペル、recieve」のように種別と語を読み上げます。英単語は 1 文字ずつの綴り読みも可能。
- ライブリージョン: タスクペインの `aria-live` 領域を更新し、スクリーンリーダー(NVDA、JAWS、ナレーター)にも通知します。
- 注釈: WordApi 1.7 対応の Word では本文に下線(批評注釈)を表示し、ポップアップから候補で置換できます。
- ステレオ定位(任意): 行内の位置を左右の定位で表現します。

入力中の語(カーソルが語の中または直後)は、区切り文字を打つまで通知を保留します。
多数の誤りが同時に現れた場合(貼り付けなど)は、まとめ音 1 回と件数の読み上げにします。

## 構成

```
word-sound-alert-addin/
  manifest.xml            アドインのマニフェスト(開発用: https://localhost:3000)
  src/core/               Word に依存しない中核(単体テスト対象)
    checker.js            内蔵チェッカー、LanguageTool チェッカー、辞書の解析
    tracker.js            誤りの差分追跡(新規・解消の判定)
    policy.js             通知ポリシー(入力中の保留、まとめ通知)
    sound.js              イヤコンの定義と再生(Web Audio)
    speech.js             読み上げ(Web Speech)
    evalLog.js            評価用ログと指標の算出
    session.js            検査→差分→通知→ログ の一巡
  src/taskpane/           Word 用タスクペイン(UI と Word との橋渡し)
  src/commands/           リボンのコマンド用ページ
  demo/                   Word なしでブラウザだけで試せるデモ
  dictionaries/           サンプル辞書
  scripts/                開発サーバー、アイコン生成
  test/                   単体テスト(node:test)
  docs/                   設計と評価計画
```

## セットアップ

必要なもの: Node.js 18 以上、Microsoft 365 の Word(Windows または Mac)。

```
cd word-sound-alert-addin
npm install
npm test
```

### ブラウザだけで動作を確かめる

```
npm run demo
```

`http://localhost:8080/` を開き、「サウンドを有効化」を押してから文書欄に入力します。

### Word で使う(開発用のサイドロード)

```
npm start
```

初回は開発用の証明書のインストールを求められます。
Word が起動し、ホームタブに「サウンド校正アシスト」のボタンが追加されます。
うまく起動しない場合は、`npm run dev-server` で `https://localhost:3000` を起動したうえで、Word の「アドイン」から `manifest.xml` を手動でサイドロードしてください。

- Windows: https://learn.microsoft.com/office/dev/add-ins/testing/create-a-network-shared-folder-catalog-for-task-pane-and-content-add-ins
- Mac: https://learn.microsoft.com/office/dev/add-ins/testing/sideload-an-office-add-in-on-mac

停止は `npm run stop` です。

### 使い方

1. タスクペインで「サウンドを有効化」を押す(ブラウザの制約で、最初に操作が必要です)。
2. 「監視を開始」を押す。以後、文書の変更を監視します。
3. 誤りが現れると効果音と読み上げで知らせ、一覧に追加されます。
4. 「次の誤りへ」「前の誤りへ」で本文の該当箇所を選択します。「候補で置換」で先頭の候補に置き換えます。
5. 「設定」で検出方法、効果音、読み上げ、辞書を変更します。設定はブラウザ(タスクペイン)のローカルストレージに保存されます。

アクセスキー: S サウンド有効化、M 監視の開始/停止、C 今すぐチェック、N 次の誤り、P 前の誤り、R 候補で置換(Windows では Alt キーと組み合わせます)。

## 評価用ログ

「評価用ログ」パネルで参加者 ID と条件を入力すると、以降の記録に付与されます。
記録される出来事: 検査、誤りの検出、通知、保留、解消、ナビゲーション、置換、設定変更。
「集計を表示」で検出数・解消数・通知から修正までの時間(平均、中央値)を表示し、「CSV を保存」または「CSV をコピー」で書き出せます。
評価の設計は docs/evaluation-plan.md を参照してください。

## 開発

- `npm test`: 中核モジュールの単体テスト。
- `npm run validate`: マニフェストの検証(Microsoft の検証サービスに接続します)。
- `npm run icons`: アイコン PNG の再生成。

本番配布時は、マニフェスト内の `https://localhost:3000` を実際の配信先 URL に置き換え、ID を発行し直してください。

## 既知の制限

- Word 標準のスペルチェック結果は取得できないため、Word が下線を引く箇所と本アドインの検出が完全には一致しません。
- LanguageTool の公開 API には利用制限があります(1 分あたりの回数、1 回の文字数)。長文や頻繁な検査には自前サーバーの利用を推奨します。
- 注釈(下線)は Word for Windows / Mac の新しいバージョン(WordApi 1.7)でのみ表示されます。
- 効果音は AudioContext の制約により、タスクペイン内で一度ボタンを押してから有効になります。
